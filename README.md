# 飞牛 DIT · fn-dit

![飞牛 DIT](fnos/ICON.PNG)

**相机存储卡照片 / 视频自动归档应用 · 开发者与发布者：fancy**

插入 SD 卡或 U 盘，由飞牛挂载后，DIT 将新素材按拍摄日期分类到你选择的 NAS 文件夹，并通过 SHA-256 去重与复制后校验保护文件完整性。

**[下载最新 FPK](https://github.com/hao93/fn-dit/releases/latest)** · [三分钟上手](docs/QUICKSTART.md) · [完整操作教程](docs/USER_GUIDE.md) · [常见问题](docs/FAQ.md)

当前版本：**v0.1.6 未签名手动安装发行版**。这是 GitHub 公开发行包，使用官方 fnpack 1.3.3 构建；没有飞牛开发者签名，也未上架官方应用商店。自动化检查通过，**未经完整 NAS 实机验收**，请先用少量测试素材验证。若设备策略拒绝未签名包，需要开发者证书，软件不会绕过系统校验。

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 系统 | 国内版飞牛 fnOS 1.2.0401 或以上 |
| 移动客户端 | 使用原生目录选择时，飞牛 App 1.34.0 或以上 |
| 运行依赖 | 应用中心安装 Node.js v22 |
| 管理账户 | 配置、授权、查看日志需要 NAS 管理员 |
| 存储卡 | 已由飞牛挂载，包含 DCIM；相机子目录也可选择 |
| 归档目标 | NAS 内部存储的已有文件夹，已授权 DIT 读写 |

用户报告的 fnOS 1.2.1010 满足声明的版本要求；不据此宣称已完成该版本的全部兼容测试。

## 第一次使用

1. 打开 [Releases](https://github.com/hao93/fn-dit/releases/latest)，下载 `fn-dit-0.1.6-unsigned.fpk`。不是 APK，也不要上传源码 ZIP。
2. 在飞牛「应用中心 → 手动安装」选择 FPK，处理 Node.js v22 依赖并打开应用。
3. 点击 **选择文件夹**，在飞牛原生弹窗中逐层选择归档目标、确认授权，再保存配置。
4. 点击 **选择存储卡**，从「外接存储」选择卡根目录或 DCIM 并确认授权。
5. 保持自动导入关闭，点击 **立即扫描一次**。首次扫描建立稳定观察记录；达到等待时长后再次扫描，检查归档结果。
6. 确认内容、目录和日期符合预期，再开启自动导入并保存。工作状态会显示下次扫描的东八区时间。

详见 [安装教程](docs/QUICKSTART.md)、[日常操作流程](docs/USER_GUIDE.md)。

## 已有功能

- 原生弹窗选择归档目标与存储卡，无需填写目标路径。
- 识别已挂载的 USB/SD 与 DCIM，显示读取权限不足、断开和无 DCIM 的原因。
- 支持 JPG/JPEG、RAF、HEIC、DNG、PNG、TIF、MOV、MP4、M4V、AVI 等；日期解析覆盖范围因格式而异。
- 按拍摄日期整理，无法解析时回退文件修改时间；支持日期下按类型或混合存放。
- SHA-256 内容去重、临时复制、复制后校验、同名冲突保护。
- 按实际文件变化观察稳定性，避免相机时间领先导致持续等待。
- 东八区运行日志、上次/下次扫描时间、持久导入历史和日志下载。
- 专用应用账户运行，默认关闭自动导入，不删除、不格式化原卡。

归档示例：

```text
Photos/
└── 2026/
    └── 2026-11-20/
        ├── RAW/DSCF1234.RAF
        ├── JPG/DSCF1234.JPG
        └── VIDEO/DSCF1235.MOV
```

## 升级、日志和排查

- 从旧版覆盖升级前，关闭自动导入并等待当前任务结束；不要先卸载。[升级与备份](docs/UPGRADE.md)
- 「导入历史」保存每轮新增、重复、待稳定和失败数量，支持逐轮查看、下载，重启后保留。[历史记录](docs/HISTORY.md)
- 卡在飞牛中可见、应用里不可读时，先使用选择存储卡授权，再检查外接存储权限。[SD 卡排查](docs/SD_CARD.md)
- 长期待稳定、未导入、时间或日期不符等问题见 [FAQ](docs/FAQ.md)。

## 开发与验证

需要 Node.js 22+、Python 3.12+ 和 Linux 官方 fnpack。日常开发：

```bash
npm test
DIT_DEV=1 DIT_DATA_DIR=/tmp/fn-dit-dev node app/server.js
```

开发模式仅监听本机 `127.0.0.1:17681`，用于本地调试；生产包使用飞牛网关及管理员身份校验。不要将开发模式暴露到公网。

[GitHub Actions](https://github.com/hao93/fn-dit/actions) 会执行功能回归、包审计、损坏包回归、真实 FPK 服务启停/历史/计划测试。当前业务回归为 51 项；CI 通过不等于 NAS 实机验收。

## 限制

不自行挂载设备，不代替独立备份。RAW/HEIC/视频的日期解析、存储卡权限、飞牛网关、断电/拔卡/空间耗尽及相册索引还需实机抽样验证。尚未实现相似照片识别、亮灯画面筛选、相机直连或自动清卡。详见 [路线图](docs/ROADMAP.md)。
