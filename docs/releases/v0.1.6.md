## 下载

选择附件 `fn-dit-0.1.6-unsigned.fpk`，不要选择 Source code ZIP。附带安装指南、FPK 校验值、包审计、构建来源信息与完整附件校验清单。

## 本版功能

- 原生弹窗选择 NAS 归档目标和外接存储卡，保存目录授权。
- 照片/视频按日期分类，SHA-256 内容去重、复制后校验和同名保护。
- 按实际变化观察文件稳定，避免相机时间领先导致长期等待。
- 上次/下次扫描与运行日志固定东八区 UTC+8。
- 每轮导入数量及逐文件日志持久保存，可查看和下载。
- fancy 署名与简约归档图标。

核心功能沿用 v0.1.5，本次补齐公开发行及维护流程和教程。

## 安装与升级

需要国内版 fnOS 1.2.0401+、Node.js v22；移动原生选择器需要飞牛 App 1.34.0+。使用 NAS 管理员账户配置。

首次安装：应用中心 → 手动安装 FPK → 选择归档目标并保存 → 选择存储卡授权 → 少量样本手动验证 → 确认后开启自动导入。

旧版升级：关闭自动导入并等任务结束，直接覆盖升级，**不要先卸载**。重新打开应用确认版本和目录权限，手动核对后再开启自动导入。
