# 三分钟上手：安装与首次导入

适用：飞牛 DIT v0.1.6，开发者/发布者 fancy，**未签名手动安装版**。未经完整 NAS 实机验收。

## 1. 准备

- fnOS 1.2.0401+，管理员账户；原生移动端选择器需要飞牛 App 1.34.0+。
- 应用中心的 Node.js v22。
- 少量已备份的测试照片/视频，以及 NAS 内部已创建的归档文件夹。

## 2. 下载并安装

打开 [最新 Release](https://github.com/hao93/fn-dit/releases/latest)，下载 `fn-dit-0.1.6-unsigned.fpk`。旁边的 SHA-256 文件用于核对下载完整性，源码 ZIP 不能作为应用安装包。

进入飞牛 **应用中心 → 手动安装 → 选择 FPK**，按系统提示处理依赖、安装位置和权限。完成后打开「飞牛 DIT」，左下角应显示 v0.1.6。

若系统拒绝未签名包，请保留错误信息。这个包没有开发者签名，不能通过改文件后缀或关闭系统校验来变成签名包。

## 3. 选择归档目标

点击 **选择文件夹** → 在飞牛弹窗中逐层打开 NAS 内部文件夹 → 选择并授权 → 回到 DIT 点击 **保存配置**。目标不能是存储卡，也不能与来源重叠。

## 4. 选择存储卡

插卡后先确认飞牛「文件管理 → 外接存储」能打开它。DIT 内点击 **选择存储卡**，选择卡根目录（例如 SD_Card_Reader）或其 DCIM，确认授权。来源通过目录读取检查后自动保存。

不要把“我的文件/目标目录”的选择按钮与“外接存储/存储卡”的按钮混用。

## 5. 先手动验证

自动导入保持关闭，点击 **立即扫描一次**。

- 第一次可能显示“待稳定”：应用要实际观察文件大小和修改标记连续不变。
- 等待设置的稳定时长后再次扫描；默认稳定等待 10 秒。
- 检查目标目录的文件数、内容、分组日期；再次扫描应显示重复而不是新增副本。
- 打开 **导入历史 → 查看日志**，核对本轮新增、重复、待稳定和失败数量。

## 6. 开启自动导入

确认结果正常后，打开「自动导入」并保存。工作状态会显示 **下次扫描（UTC+8）**。任务执行中，下次计划会在本轮结束后安排；自动导入关闭时不显示一个虚构时间。

## 完成检查

- [ ] 应用版本和依赖正确
- [ ] 目标目录选择并保存，应用可写
- [ ] 存储卡已由飞牛挂载，应用可读取 DCIM
- [ ] 少量样本导入成功，内容和日期已核对
- [ ] 重复扫描不重复复制，历史日志可查看
- [ ] 确认后才开启自动导入
