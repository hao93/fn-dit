# 升级、备份与回退

## 从 v0.1.x 升级到 v0.1.6

1. 在 DIT 关闭自动导入并保存，等待当前任务结束。
2. 下载需要留存的运行日志；记录当前版本、目标目录和来源选择。重要素材保持独立备份。
3. 从 [最新 Release](https://github.com/hao93/fn-dit/releases/latest) 下载 FPK，在应用中心手动安装并覆盖升级。**不要先卸载旧版**。
4. 按应用中心流程处理依赖与启动，关闭后重新打开 DIT，确认左下角版本为 v0.1.6。
5. 检查目标、来源、自动导入开关、历史列表。权限失效时重新通过原生弹窗授权。
6. 用少量测试素材手动扫描，核对后再开启自动导入。

## 哪些数据需要保留

应用运行数据位于飞牛提供的 `TRIM_PKGVAR`，常见实际位置是 `/volN/@appdata/fn-dit`，以设备实际安装位置为准。重要内容包括：

| 文件或目录 | 用途 |
| --- | --- |
| `config.json` | 配置、目标和来源 |
| `index.jsonl` | SHA-256 去重索引及已归档目标 |
| `import.log` | 总运行日志 |
| `history/` | 每轮数量、结果及详细日志 |
| `service.log` | 后台启动和异常信息 |

正常重启和覆盖升级按相同应用标识使用这些数据。卸载时选择删除应用数据会移除它们。应用外的归档目标目录独立于应用数据；本项目卸载脚本不主动删除用户媒体。

如需备份完整应用数据，应先停止 DIT，再使用设备上有权限的备份方式复制应用数据目录。不要在活动复制过程中编辑索引或配置。网页日志下载只导出日志，不等于完整数据备份。

## 回退边界

飞牛是否允许降级由系统决定，本项目不能保证直接安装较低版本。先保存日志和数据备份，检查拟回退版本的数据格式、签名及系统要求。必要时通过应用中心支持的方式恢复，不要为降级先删除数据或手工修改 manifest 版本。

v0.1.6 没有引入新的业务数据格式；其核心功能沿用 v0.1.5，主要整理公开发行、教程和发布流程。但具体设备上的覆盖升级、回退与权限继承仍需实机验证。
