# 开发路线

## v0.1.6 已交付范围

- 官方 fnpack Linux 构建、校验和可重复的 GitHub 发布流程。
- 原生目标目录/存储卡选择、挂载发现、权限原因提示。
- 拍摄日期分类、SHA-256 去重与复制后校验、同名保护。
- 文件稳定观察、东八区日志与上次/下次扫描时间。
- 持久导入历史、逐轮数量和日志下载，fancy 署名与简约图标。
- 安装、操作、升级、排查和维护者发布教程。

## 下一阶段：验收与兼容性

优先完成真实 fnOS 安装/覆盖升级、原生网关与授权、不同读卡器与文件系统，以及断电/拔卡/空间不足的验收。完善媒体日期样本、持续插卡期间新文件发现及大型照片库性能。

## 后续候选功能

设备白名单、导入完成通知、更多文件名模板、索引维护与修复、可导出校验清单和相册集成。相似照片或亮灯画面识别属于尚未实现的独立需求，不能作为当前功能承诺。

具体版本安排由问题反馈和验收结果决定。
