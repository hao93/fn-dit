# 测试与验证范围

当前版本 v0.1.6。业务回归基线为 **51 项**：媒体日期、分类、复制校验、重复与冲突、文件稳定观察、东八区时间、来源发现、原生目录选择回调、历史持久化、日志分页及扫描计划等。

## 自动执行

1. Node.js 22 在 Linux 运行 `node --test tests/*.test.js`。
2. JavaScript 语法检查。
3. 官方 fnpack 1.3.3 的固定下载哈希验证与实际构建。
4. staging 和最终 FPK 审计：manifest、版本、fancy 署名、包账户、API scope、9 个生命周期脚本、执行位、LF、64/256 图标、网页图标、SDK 哈希、源码及 app.tgz MD5。
5. **5 项 FPK 回归**：真实包通过；缺安装脚本、执行位损坏、错误 checksum、旧式归档路径均被拦截。
6. 从实际 FPK 解出服务，在 Linux 验证启动/重复启动/状态/停止、管理员与未认证请求、页面/模块、目录检查、历史列表/详情/下载、手动扫描落盘、重启保留、下一轮自动计划及启动崩溃反馈。
7. 发布前核对请求版本与文件校验；上传草稿后逐个核验服务器 SHA-256，再公开为 Latest。

以 [对应提交的 Actions 实际结果](https://github.com/hao93/fn-dit/actions) 为准。新版本构建产物必须和其源提交对应，不能借用旧版本的测试结论。

## 已有本地证据

实际测试文件完成 SHA-256 校验、未来时间文件经观察后导入、同名不同内容不覆盖、历史数量与逐文件日志持久保留。本地浏览器检查了目录按钮、回调/取消、东八区状态和历史详情。界面样本不是 NAS 的真实同步结果。

## 仍需 NAS 实机验收

- v0.1.6 在 fnOS 应用中心安装/覆盖升级及设备签名策略。
- Node.js v22 依赖、统一网关和原生目录弹窗。
- 不同 USB/SD、文件系统、挂载路径和授权可见范围。
- 真实 RAW/HEIC/视频日期、相机时钟与分类时区。
- 大型照片库性能、断电、拔卡、目标/应用数据空间耗尽。
- 飞牛相册索引、完整回退流程和系统升级兼容。

用户报告的 fnOS 1.2.1010 满足声明的最低要求；本项目没有把这个报告当作已完成全部验收。第一次请使用少量已备份样本，确认后再开启自动导入。
