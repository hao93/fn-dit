# 测试及验收

## 本地测试

环境：Node.js v22.16.0，2026-11-20。

```bash
npm test
```

已验证以下 8 个测试：

1. 扩展名与分类大小写不敏感。
2. 严格的日历日期校验。
3. JPEG EXIF DateTimeOriginal 读取。
4. QuickTime mvhd 创建时间读取。
5. RAF/JPG 均保留、重复素材不重复复制、索引重启持久。
6. 同名不同内容不会覆盖。
7. 尚未稳定写入的来源文件延迟处理。
8. 仅允许合法 NAS 内部 `/volN` 目标目录。
